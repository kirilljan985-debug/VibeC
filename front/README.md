# front/ — интерфейс VibeC

Первый этап фронтенда реализован 10.10.2026 по контракту v1.0.
HTML, CSS и обычный JavaScript, без сборки, npm, CDN и внешних шрифтов.

## Что сделано

- Обзор курса: продолжение текущего урока, общий прогресс, карточки треков.
- Основные уроки и экспресс-курс: номера, названия, описания, статусы, бейджи квизов и карточек; фильтр по прохождению.
- Просмотр урока в iframe с сохранением его собственных стилей и интерактива; предыдущий/следующий урок по API.
- Полнотекстовый поиск с задержкой 300 мс, отменой устаревших запросов и подсветкой совпадения в сниппете; Ctrl+K переводит фокус в поиск.
- Отметка «пройдено» через API, мгновенное обновление и откат при ошибке. Пользовательские отметки имеют приоритет над статусом преподавателя. Снятие преподавательского `done` сохраняет `not-started`, поскольку удаление отметки восстановило бы `done`.
- Справочники, материалы, документы и записи прогресса. Markdown читается безопасным обычным текстом; HTML и PDF открываются во встроенном просмотре либо отдельно.
- Подхват каталога при возвращении в окно, раз в минуту в видимой вкладке и по кнопке обновления. Просмотр открытого урока при фоновом обновлении не перезагружается.
- Адаптивная вёрстка, навигация с клавиатуры, подписи элементов, состояния загрузки, пустого каталога и ошибок сервера.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Каркас, меню, строка поиска, основной контейнер |
| `styles.css` | Тёмная тема, карточки, просмотр и адаптивная вёрстка |
| `app.js` | API, маршруты в URL, поиск, отображение каталога и сохранение отметок |

Все данные берутся через существующее API; содержимое папки «обучение» не сканируется фронтендом. Ссылки на материалы используют путь файла из каталога и остаются стабильными при добавлении новых материалов. Код сервера, контракта и тестов не изменялся.

## Проверка руками

1. Из корня проекта выполнить `python server/app.py --no-browser` либо открыть `запуск.bat`.
2. Перейти на `http://127.0.0.1:8765/`. Должны появиться реальные треки, уроки и материалы.
3. Нажать «Продолжить урок»: проверить iframe, навигацию и ссылку «Открыть отдельно».
4. Изменить отметку прохождения, перезагрузить страницу, проверить сохранение. Снять тестовую отметку.
5. Найти «глоссарий», перейти из результатов в урок. Проверить отсутствие результатов для произвольного несуществующего слова.
6. В разделе уроков переключить фильтры. В библиотеке открыть справочник и Markdown-документ.
7. Уменьшить ширину окна: меню переносится, карточки идут в одну колонку, горизонтальной прокрутки страницы нет.

## Проведённые проверки

- Синтаксис JavaScript: `node --check front/app.js`; чистота изменений: `git diff --check`.
- Все существующие серверные тесты: **30/30**.
- Браузер на реальной папке: 3 трека, 11 основных и 6 экспресс-уроков, 15 материалов; поиск, iframe, чтение документа, фильтр и сохранение/снятие отметки после перезагрузки.
- Мобильная ширина 390 px: проверена в браузере, горизонтального переполнения нет.
- Временная фикстура: пустой каталог, два новых трека, 12 уроков в одном треке и длинные заголовки.
- Остановленный тестовый сервер: ошибка обновления оставляет каталог на экране, ошибка сохранения возвращает исходную отметку.
- Консоль браузера на рабочем сервере: ошибок JavaScript не обнаружено.
