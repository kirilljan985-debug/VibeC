# 🧠 ПАМЯТЬ ПРОЕКТА «VibeC»

**Файл памяти приложения.** Агент читает его первым в каждой новой сессии работы над проектом: здесь карта проекта, роли, статус и журнал решений. Обновляется после каждого этапа. Создан: 10.10.2026.

---

## 🖥️ Что за проект

- **Название:** VibeC — интерактивный портал курса
- **Задача:** удобное, практичное и красивое интерактивное приложение **по составу папки `обучение`** (уроки, треки, глоссарии, экспресс-курс, документы, прогресс). Дополняется **само** — новые уроки, положенные в папку, появляются в приложении без правки кода
- **Платформа:** локальный веб-приложение. Бэкенд — Python 3.14 **только стандартная библиотека** (никаких pip-зависимостей: запускается на любой машине студента одной командой)
- **Источник данных:** `~/Desktop/обучение` — единственный источник правды. Бэкенд ничего не копирует и не дублирует: сканирует папку и раздаёт её содержимое

## 👥 Роли (та же схема, что в «Пепле»)

| Кто | Что делает |
|---|---|
| **Студент** | продюсер: ставит задачи, ревьюит диффы, проверяет руками, принимает этапы |
| **ZCode (бэкенд)** | `server/`, `tests/`: сканер папки обучения, HTTP API, хранилище прогресса, контракт, интеграция фронта |
| **GPT (фронт)** | `front/`: весь видимый слой — дашборд, списки уроков, просмотр, поиск, прогресс. Онбординг — `ЗАДАНИЕ-ДЛЯ-GPT.md` |

**Зоны и стыковка:** [`ИНТЕРФЕЙС.md`](ИНТЕРФЕЙС.md) — контракт v1.0 (эндпоинты API, схемы JSON, границы зон). Агенты не пишут в чужих зонах; изменения контракта — через продюсера.

## 📜 Журнал решений (vibe-дневник)

Каждое нетривиальное решение — строкой сюда. Это история «почему так».

| Дата | Решение | Почему |
|---|---|---|
| 10.10.2026 | Бэкенд на чистом Python stdlib (http.server), без фреймворков и pip | Приложение должно запускаться на машине студента одной командой без установки зависимостей; объём API небольшой — фреймворк не окупается |
| 10.10.2026 | Бэкенд ничего не копирует из папки «обучение»: сканирует живую папку на каждый запрос каталога | Папка — единственный источник правды; новый урок в папке = новая строка в приложении автоматически, синхронизация не нужна |
| 10.10.2026 | Статусы уроков при первом запуске выводятся из таблицы «Статус» в `обучение/ПАМЯТЬ.md` (эмодзи ✅/📖/⏳/❓) | Преподаватель уже ведёт статусы там; дублировать ввод некому. Отметки, сделанные в приложении, живут в `data/progress.json` и перекрывают семена |
| 10.10.2026 | Прогресс — на сервере (JSON-файл), не в localStorage | localStorage привязан к браузеру и теряется; файл прогресса можно бэкапить вместе с репозиторием данных, и в будущем его увидит любой клиент |
| 10.10.2026 | Уроки раздаются статикой по `/content/<путь внутри обучения>` — фронт встраивает их в iframe | Уроки уже самодостаточные HTML со своими квизами/флеш-картами и относительными ссылками на `компоненты/`; зеркало путей 1:1 сохраняет их работоспособность |
| 10.10.2026 | Неизвестные подпапки `уроки/` становятся новыми треками автоматически | Курс будет расти (недели 3–4: новые темы); бэкенд не должен требовать правки кода на каждый новый раздел |
| 10.10.2026 | Порт 8765, хост 127.0.0.1 (переопределяется VIBEC_PORT / VIBEC_HOST) | Сервер не должен торчать в сеть; порт выбран непопулярный, чтобы не конфликтовать |
| 10.10.2026 | `rpg-adventure/`, `python-lab/` и `компоненты/` сканером игнорируются как разделы курса | Это отдельные проекты/служебная папка; в портале им место в других разделах, не в списке уроков |
| 10.10.2026 | POST /api/progress проверяет существование урока в каталоге (404), снятие — без проверки | Если урок удалён из папки, фронт больше не создаст осиротевшую запись в progress.json; снятие без проверки позволяет чистить старых сирот |
| 10.10.2026 | Приложение запускается VibeC.exe из корня репозитория; в frozen-режиме пути считаются от папки exe | PyInstaller распаковывается во временную папку, `__file__` там неверен — ориентируемся на `sys.executable`; ярлык на рабочем столе указывает на exe, всё остальное (front/, data/, обучение) подхватывается по соседству |
| 10.10.2026 | Иконка VC рисуется кодом (`tools/make_icon.py`, Pillow), а не скачана | Права чужих иконок не трогаем; вид полностью под контролем (тёмный фон, объём, тень, свечение), иконка воспроизводимо пересобирается одной командой |
| 10.10.2026 | Экспресс-ветка: id курса = имя папки, id урока = `<курс>-<номер>`; описания курсов читаются из index.html курса | Новые грейды («вайб-кодер-…» и любые будущие) подхватываются без правки кода; человекочитаемые названия берутся из самого курса, а не зашиваются в сканер |
| 10.10.2026 | Прогресс старого экспресс-курса перенесён скриптом, а не правилкой рук: `tools/migrate_progress_express.py` | Разовая миграция данных воспроизводима и остаётся в истории: видно, что express-0001…0006 стали `вайб-кодер-junior-0001…0006`, студент ничего не потерял |
| 11.10.2026 | **exe собирается в оконном режиме (--windowed): консоли при запуске нет**. Сервер приучен жить без консоли: печати безопасны (stdout None), лог запросов отключается, краш пишется в `data/last-error.log`, автостоп после 30 мин бездействия (`VIBEC_IDLE_EXIT_MINUTES`), повторный запуск открывает браузер на работающем экземпляре (проба /api/meta до привязки) | Ярлык на рабочем столе не должен выплёвывать чёрное окно. Но без консоли некому нажать Ctrl+C и некуда вывести ошибку — поэтому автостоп, файловый краш-лог и «второй запуск = открыть существующий» |
| 11.10.2026 | `allow_reuse_address = False` у сервера | Windows-семантика SO_REUSEADDR позволяет молча привязаться к уже занятому порту: второй экземпляр висит без запросов и вечно жив. Занятый порт = честная ошибка привязки; «уже запущен» ловится пробой /api/meta до привязки |
| 11.10.2026 | **Дедуп вкладок**: повторный запуск exe при открытом портале не открывает вторую вкладку. Решение — по `/api/meta`: `front_alive` (фронт опрашивает сервер ежеминутно, пока вкладка активна → окно 120 с) и `uptime_seconds` (льгота 15 с на старт). Браузер открывается только если вкладка не видна серверу (закрыта) | `webbrowser.open` умеет только «открыть новую вкладку», сфокусировать чужую нельзя. Живая вкладка = нет новых вкладок; закрыл вкладку → клик снова открывает портал (на уже работающем сервере). Нюанс: свёрнутое/фоновое окно браузера ставит опрос на паузу (document.hidden) — через 2 мин «вкладка» считается закрытой, и клик откроет новую вкладку |
| 11.10.2026 | **Фокус окна вместо новой вкладки**: повторный клик при свёрнутом браузере разворачивает и фокусирует существующее окно с порталом (Win32 через PowerShell: поиск окна с «VibeC» в заголовке — фронт всегда держит его в document.title; окно папки с именем ровно «VibeC» исключено; IsIconic → SW_RESTORE; ALT-трюк перед SetForegroundWindow, чтобы фокус брался из фонового процесса). Новая вкладка — только если окна нет вообще | Пауза опроса в свёрнутом окне больше не порождает дубль-вкладку: заголовок окна надёжен независимо от document.hidden. Ограничение: фокусируется окно, а не конкретная вкладка — если в браузере активна другая вкладка, портал надо кликнуть вручную |
| 14.10.2026 | Раздел «Разработка игры» = один файл `разработка-игры.md` в корне обучения, а не папка-трек: каталог отдаёт его полем `game_dev`, фронт — отдельной вкладкой с документом целиком | Преподаватель ведёт раздел одним документом (фазы, циклы сопровождения); заводить папку под это — лишняя структура. Файл исчезнет → поле станет null → вкладка честно скажет «раздела нет» |
| 14.10.2026 | Документы в папке трека (программа курса, README) отдаются полем `files` у трека, а не перекладываются в справочники | Программа принадлежит своему курсу: лежит рядом с уроками, показывается ссылкой в карточке трека; новые документы трека подхватываются без правки кода |
| 14.10.2026 | `демо-репо/` (учебный репозиторий трека А) намеренно НЕ показан в портале | Это рабочий репозиторий студента (git, __pycache__), а не материал для чтения; в портале ему место только если преподаватель сделает из него урок/справочник |

Ярлык возвращён на рабочий стол и перепристрелен к exe на новом месте | Приложение не должно ломаться от переноса своей папки: источник правды — курсы, а не соседство папок. Теперь VibeC работает и рядом с «обучением», и внутри него, и уровнем выше; 6 тестов-резолвера покрывают все варианты |

## ⚠️ Не забыть

- Контракт менять только через версию в `ИНТЕРФЕЙС.md` (история версий внизу файла)
- Файл `data/progress.json` — в git не попадает (runtime-данные), но его стоит бэкапить пользователю
- Кодировка: консоль Windows может быть не UTF-8 — сервер печатает лог ASCII-безопасно, файлы читаются строго в UTF-8
- Фронт приходит от GPT в `front/` — сервер уже отдаёт `front/index.html` на `/`, ничего перенастраивать не нужно
