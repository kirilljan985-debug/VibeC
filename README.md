# 🖥️ VibeC — портал курса

Интерактивное веб-приложение поверх папки **«обучение»**: уроки трёх разделов, экспресс-курс, справочники, документы, поиск и персональный прогресс. Каталог строится **сканированием живой папки** — новый урок, положенный преподавателем, появляется в приложении сам.

## Запуск

**Ярлык «VibeC» на рабочем столе** (иконка VC) — поднимет сервер и откроет браузер на `http://127.0.0.1:8765/`. Консоль при этом **не появляется**: exe собран в оконном режиме. Повторный клик по ярлыку **не создаёт дублирующих вкладок**: если окно браузера с порталом уже есть (даже свёрнутое), оно разворачивается и получает фокус; новая вкладка открывается только если портала на экране нет вообще. Сервер сам остановится после 30 минут бездействия (`VIBEC_IDLE_EXIT_MINUTES=0` отключает автостоп). Если exe молча не стартовал — причина в `data/last-error.log`. Пересборка: `python -m PyInstaller --noconfirm --onefile --windowed --name VibeC --icon assets/vibec.ico --paths server server/app.py`.

Или из исходников: двойной клик по **`запуск.bat`**, либо:

```bash
python server/app.py
```

Требования: Python 3.10+ (проверено на 3.14), **без pip-зависимостей**.

Папку VibeC можно располагать где угодно: приложение само находит папку «обучение» — рядом с собой, внутри неё или уровнем выше. Другая папка:

```bash
python server/app.py --root "C:/путь/к/обучение"
# или переменной окружения VIBEC_CONTENT_ROOT
```

Порт/хост: `--port`, `--host` (или `VIBEC_PORT`, `VIBEC_HOST`). Отключить авт-opening браузера: `--no-browser`.

## Структура

```
server/   ← бэкенд: app.py (сервер), scanner.py (сканер папки), store.py (прогресс), config.py
front/    ← фронт (пишет агент GPT; пока пусто — сервер показывает страницу-заглушку)
tests/    ← тесты (30 шт.) + fixture.py — миниатюра папки «обучение»
data/     ← runtime: progress.json (отметки прогресса; в git не попадает)
```

## Тесты

```bash
python -m unittest discover -s tests
```

Тесты работают на фикстуре-миниатюре и не требуют реальной папки «обучение».
